# my_lang_ftl_prak - ПОЛИЗ Генератор и Интерпретатор

**Компилятор для простого языка программирования с поддержкой функций, переменных**

## Быстрый Старт

### 1️⃣ Сборка проекта
```bash
cd /home/afa/CLionProjects/my_lang_ftl_prak
cmake --build cmake-build-debug --target my_lang_ftl_prak
```

### 2️⃣ Запуск программы
```bash
./cmake-build-debug/my_lang_ftl_prak program.txt
```

### 3️⃣ Запуск автотестов
```bash
# Основной набор (13 тестов)
python3 autotest.py

# Расширенный набор с функциями (19 тестов)
python3 autotest_extended.py

# Просмотр отчёта
python3 test_report.py
```

## Что Поддерживается

###  Язык
- Переменные (int, double, string)
- Пользовательские cтруктуры данных
- Функции с параметрами и возвратом
- Арифметика (+, -, *, %)
- Сравнения (==, <, >, <=, >=, !=)
- Логика (&&, ||)
- IF / ELSE блоки
- WHILE циклы
- Локальные и глобальные переменные
- Вложенные функции и вызовы

### ПОЛИЗ (Обратная польская нотация)
- 30+ типов инструкций
- Оптимизация кода
- Управление регистрами
- Поддержка меток и переходов

### Интерпретатор
- Виртуальная машина с 16 регистрами
- Стек для параметров и локальных переменных
- Step-by-step отладка
- Вывод и ввод данных

## Примеры

### Пример 1: Простая функция
```c
int add(int a, int b) {
    return a + b;
}

int main() {
    int result;
    result = add(5, 3);
}
```

### Пример 2: Цикл и условие
```c
int main() {
    int x;
    x = 0;
    while (x < 10) {
        if (x == 5) {
            x = x + 2;
        } else {
            x = x + 1;
        }
    }
}
```

### Пример 3: Вложенные вызовы
```c
int double_val(int x) {
    return x + x;
}

int increment(int x) {
    return x + 1;
}

int main() {
    int result;
    result = double_val(increment(5));
}
```
